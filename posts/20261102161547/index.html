FCN: Fully Convolutional Networks for Semantic Segmentation#

论文链接：https://arxiv.org/abs/1411.4038v1

论文代码：

语义分割开山之作，首次提出全卷积网络（FCN），彻底把分类 CNN 改造为像素级分割模型，后续 U-Net、SegNet、DeepLab 等所有分割网络均基于 FCN 思想拓展。

论文提出了FCN网络架构，主要为了解决两个问题，一是将传统卷积神经网络（CNN）的全连接层替换为卷积层，全连接导致的空间信息损失问题；二是转置卷积上采样 + 跳跃连接，解决下采样带来分辨率丢失问题。当然，额外还有一些优点，比如实现了对任意大小输入图像的像素级分类输出。

Deeplab V3+：Encoder-Decoder with Atrous Separable Convolution for Semantic Image Segmentation#

链接：https://arxiv.org/abs/1802.02611

这是 DeepLabv3+，由 Liang-Chieh Chen 等人发表于 ECCV 2018，是 DeepLab 系列的集大成之作，也是语义分割领域的一代经典基线。

一、背景与动机：DeepLab 系列的演进

DeepLab 系列一直围绕一个核心问题：如何在保留空间分辨率的同时扩大感受野。

┌───────┬────────────────────────────────┬───────────────────────────────────────┐

│ 版本 │ 核心机制 │ 局限 │

├───────┼────────────────────────────────┼───────────────────────────────────────┤

│ v1/v2 │ 空洞卷积 + ASPP │ 较基础 │

├───────┼────────────────────────────────┼───────────────────────────────────────┤

│ v3 │ 改进的 ASPP + 全局平均池化分支 │ 仍采用 “编码器输出后直接上采样”，细节恢复不足 │

└───────┴────────────────────────────────┴────────────────────────────────────────┘

DeepLabv3 的输出步长（output stride, OS）通常为 16 或 8，即特征图比输入小 16/8 倍，靠空洞卷积保持感受野，但最终边界细节仍依赖单次双线性上采样，较为粗糙。

与此同时，encoder-decoder 结构（如 U-Net、RefineNet）在恢复细节上表现更好：decoder通过逐步融合低层高分辨率特征来精修边界。

DeepLabv3+ 的动机就是：把 DeepLabv3 的强大编码器（空洞卷积 + ASPP）与 encoder-decoder 的精细解码能力结合起来。

二、核心贡献

贡献 1：将 DeepLabv3 改造为 encoder-decoder 结构

Encoder（编码器）

  • 主干网络（如 ResNet）提取特征，采用空洞卷积控制 output stride。

  • 顶层低分辨率特征送入 ASPP 模块：

    • 1×1 卷积分支

    • 三个不同膨胀率（rates，如 6/12/18）的 3×3 空洞卷积分支

    • 全局平均池化（GAP）分支（image-level pooling）

  • 各分支拼接（concat）后再过一个 1×1 卷积，得到编码器输出。

Decoder（解码器）—— 关键创新

DeepLabv3+ 没有照搬 U-Net 的多级对称解码，而是采用 “轻量两级上采样”：

ASPP输出(OS=16)

│ 1×1 conv 降维

▼ 双线性上采样 ×4 ──┐

│ (到 OS=4)

主干浅层特征(OS=4) ─1×1 conv降维─┘

│ concat

▼

3×3 conv → 3×3 conv ← 两层卷积精修

▼ 双线性上采样 ×4

最终分割图 (OS=1)

关键设计点：

  1. 只用一层浅层特征（通常是 backbone 的 stride=4 层，如 ResNet 的第一个 block 输出），而非逐级融合所有尺度。这样 decoder 轻量、高效。

  2. 1×1 卷积降维：浅层特征通道数大（如 256），先用 1×1 卷积降到 48 维再 concat，避免浅层特征主导、并降低计算量。

  3. 两层 3×3 卷积精修：concat 后用两个 3×3 卷积细化特征，再上采样回原图分辨率。

  4. output stride 灵活：训练时用 OS=16 求速度，推理时可切到 OS=8 提精度（只需改空洞率，无需改架构）。

贡献 2：Atrous Separable Convolution（空洞深度可分离卷积）

这是论文标题后半部分的创新，用于降低 ASPP 和 decoder 中 3×3 卷积的计算成本。

它把两件事合二为一：

  1. Atrous（空洞）卷积：在卷积核元素间插入空洞，扩大感受野而不增参数量、不降分辨率。

  2. Separable（深度可分离）卷积：

  • Depthwise：每个输入通道单独用一个卷积核（如 3×3 空洞）。

  • Pointwise：1×1 卷积做通道间信息融合。

空洞深度可分离卷积 = 空洞 depthwise + pointwise。

计算量对比

以 3×3 空洞卷积、输入输出通道均为 为例：

  • 标准空洞卷积：参数量 ≈

  • 空洞深度可分离卷积：参数量 ≈ （depthwise + pointwise ）

当 较大时，后者远小于前者（约省 ）。

论文引用 MobileNet 的结论：使用深度可分离卷积可在几乎不损失精度的情况下大幅降低计算量（约 1~2 数量级），这让 DeepLabv3+在移动端也能高效运行。

DeepLabv3+ 把 ASPP 中所有 3×3 空洞卷积、decoder 中所有 3×3 卷积都换成了这种可分离版本。

三、实验亮点

  1. 数据集与主干

  • 在 PASCAL VOC 2012（含额外标注，10582 训练图）、Cityscapes、PASCAL-Context 上评测。

  • 主干网络：ResNet-50 / ResNet-101 / Xception。

  1. encoder-decoder vs. 纯 DeepLabv3

  • 引入 decoder 后，相比直接上采样的 DeepLabv3，mIoU 提升约 1~2 个点，尤其在物体边界处改善明显。

  • 在 OS=16 下，decoder 用浅层特征带来的收益尤为突出（因为高层特征分辨率低，更需要浅层细节补偿）。

  1. ASPP vs. 不同 decoder 设计
  • 论文实验了"加 ASPP" vs “不加 ASPP（只用 decoder 融合多尺度浅层特征）"，发现 ASPP + decoder 的组合最优——空洞卷积的多尺度上下文与浅层细节是互补的，缺一不可。
  1. Xception 主干 + 深度可分离卷积

  • 把 ResNet 换成改进的 Xception（更深的 depthwise separable 结构，改动 entry flow、加更多层、用 BN+ReLU），并在ASPP/decoder 全部用空洞深度可分离卷积：

    • 精度进一步提升（VOC 上达 89% mIoU，当时 SOTA）。

    • 计算量大幅下降，更适合部署。

  • 在 Cityscapes 上达到约 82.1% mIoU，验证集与测试集均表现优异。

  1. 速度-精度权衡

通过调整 output stride（8 vs 16）、decoder 卷积通道数、是否用可分离卷积，可在精度与速度间灵活权衡，覆盖服务器端到移动端。

四、与同类工作的关系

  • vs. U-Net / RefineNet：DeepLabv3+ 保留了 encoder-decoder 思想，但 decoder 极度精简（只取一层浅层特征 + 两层 3×3 卷积），而非逐级对称上采样，更轻量。

  • vs. PSPNet：PSPNet 用金字塔池化抓全局上下文；DeepLabv3+ 用 ASPP（不同空洞率）抓多尺度上下文，并额外加 decoder 恢复细节，对边界更友好。

  • vs. DeepLabv3：v3+ 是 v3 的"加 decoder"增强版，ASPP 部分基本继承，主要改进在 decoder 与可分离卷积。

五、意义与启发

  1. 集大成：DeepLabv3+ 把"空洞卷积（扩大感受野）+ ASPP（多尺度上下文）+ encoder-decoder（细节恢复）+ 深度可分离卷积（轻量化）“四者整合，是 DeepLab 系列的终结篇，也成为语义分割的标准基线，被广泛引用与复现。

  2. 轻量 decoder即足够：论文证明"不需要复杂的逐级解码，仅融合一层浅层高分辨率特征"就能大幅提升边界质量，这对后续轻量分割网络（如BiSeNet、Fast-SCNN）的设计有重要启发。

  3. 空洞可分离卷积的普适价值：把"扩大感受野"和"降低计算量"统一在一种算子中，是后续高效分割/检测模块（如 LR-ASPP、MobileSeg系列）的常用技巧。

  4. 训练-推理 OS 解耦：训练用大 OS 省显存、推理用小 OS 提精度，这种"同架构、换参数"的灵活性成为分割领域的常见实践。

一句话总结：DeepLabv3+ 在 DeepLabv3 的 ASPP 编码器基础上，嫁接了一个轻量的浅层特征 decoder

以精修边界，并全面采用空洞深度可分离卷积降低计算量，从而在精度与速度上同时取得突破，成为语义分割领域的经典基线。

RepVGG: Making VGG-style ConvNets Great Again#

论文地址：https://arxiv.org/abs/2101.03697 (CVPR2021)

论文源码：https://github.com/megvii-model/RepVGG

这是 CVPR 2021 的一篇论文，核心思想是：用结构重参数化（Structural Re-parameterization）让一个训练时为多分支结构的网络，在推理时等价转换为单分支的 VGG/ResNet 风格网络，从而兼顾训练时的精度与推理时的速度。

  • 3x3卷积分支（提取特征） + 1x1卷积分支（补充不同感受野的特征） + Identity分支（残差连接，改善梯度）

  • 卷积和BN合并，3卷积合并1卷积（ (W₁x + b₁) + (W₂x + b₂) + (W₃x + b₃) = (W₁+W₂+W₃)x + (b₁+b₂+b₃)）

  • 这一步是在onnx导出还是在哪里实现的？

一、动机：为什么要"复活"VGG？

作者指出，VGG 风格的网络（纯串联的 3×3 卷积 + ReLU）有三个对部署友好的优势：

  1. 推理快：单分支结构内存访问开销小，没有分支融合的额外耗时。

  2. 省显存：不需要保存中间多分支的结果。

  3. 灵活：易于针对不同硬件/算子库做量化、剪枝等优化。

但 VGG 之所以被淘汰，是因为它精度不够高——缺少 ResNet 那样的多分支（恒等映射 + 1×1

卷积）结构，导致训练深层网络时梯度流差、表达力不足。

于是核心矛盾是：多分支结构利于训练精度，单分支结构利于推理效率。

二、核心方法：结构重参数化

  1. 训练时结构：3 分支

每个 RepVGG Block 在训练时有三条并行分支：

┌── 3×3 conv + BN ──┐

输入 ────┼── 1×1 conv + BN ──┼── 相加 ── ReLU ── 输出

└── Identity(BN) ──┘

  • 3×3 分支：主要特征提取

  • 1×1 分支：补充不同感受野的特征

  • Identity 分支（带 BN）：当输入输出通道数、空间尺寸一致时存在，相当于残差连接，改善梯度流

这种结构和 ResNet 类似，能获得高精度。

  1. 推理时结构：单分支

部署时把上面的三分支等价融合成一个 3×3 卷积：

输入 ── 3×3 conv + ReLU ── 输出

融合后变成了纯 VGG 风格，没有多余的分支开销。

  1. 为什么能融合？—— 重参数化推导

关键在于 卷积是线性的，BN 在推理时也是线性的，所以可以把三者合并。

步骤一：把每个分支的 Conv + BN 融合成一个带偏置的卷积

BN 在推理阶段的公式为：

y = γ·(x - μ)/√(σ² + ε) + β

这是一个仿射变换（线性 + 偏置）。设：

  • 卷积核权重为 W，则卷积输出 W*x（无偏置时）

  • BN 参数 γ, β, μ, σ², ε

可推导出等效卷积核与偏置：

W’ = W · (γ / √(σ² + ε))

b’ = β - γ·μ / √(σ² + ε)

于是每个分支都变成 Conv(W’, b’)。

步骤二：把三个分支的卷积相加

因为三个分支对同一输入做卷积后逐元素相加，而卷积对加法满足分配律：

(W₁x + b₁) + (W₂x + b₂) + (W₃x + b₃) = (W₁+W₂+W₃)x + (b₁+b₂+b₃)

处理 1×1 分支和 Identity 分支：

  • 1×1 卷积：把它的核零填充成 3×3，就能直接加到 3×3 核上。

  • Identity 分支（没有卷积，只有 BN）：相当于一个"以恒等为单位冲激"的卷积——构造一个中心为 1、其余为 0 的 3×3 核，再乘以 BN 的等效系数，就能并入。

最终得到一个单一的 3×3 卷积（带偏置），与原三分支在数学上完全等价。

▎ 注意：融合只在 BN 处于推理模式（用训练集的滑动均值/方差）时才等价。所以训练完、转为 eval 模式后再融合。

三、网络整体设计

RepVGG 是一个类似 VGG 的 stage 架构，共 5 个 stage，每个 stage 由若干个 RepVGG Block 堆叠：

  • Layer placement：每个 stage 第一个 block 做 stride=2 下采样（类似 ResNet），此时 Identity 分支不存在（输入输出尺寸不同）。

  • 逐阶段变宽：每个 stage 的通道数按基础倍数 a, b 缩放，且越深的 stage 越宽（2a, 4a, 8a 之类）。

  • 针对性加深变宽：通过不同的 a, b 和 stage 深度配置，得到一个模型族：

    • RepVGG-A0/A1/A2：轻量级

    • RepVGG-B0/B1/B2/B3：更大，追求更高精度

    • RepVGG-B1g2/g4、B2g4：使用分组卷积（groupwise conv）的变体，进一步权衡速度

四、实验结果亮点

  • ImageNet 分类：RepVGG-B2 在仅 80% 训练 epoch 下达到 Top-1 80%+，超过 ResNet-152、EfficientNet 等同期模型，且推理速度更快。

  • 速度：在 GPU 和专用加速硬件上，同等精度下比多分支网络（如 ResNet、ResNeXt）快不少，因为推理时是纯单分支。

  • 等价性验证：作者实测融合前后输出几乎一致（差异在浮点误差量级），证明重参数化是数学等价的。

  • 迁移到检测/分割：作为 backbone 加在 CenterNet/PSPNet 上也带来提升。

五、意义与启发

1.训练-推理解耦：开创性地提出"训练用复杂结构、推理用简单结构"的设计范式，不必为了部署而牺牲精度，也不必为了精度而牺牲速度。

  1. 结构重参数化成为通用工具：后续很多工作（如 RepVGG 后续系列、DBB/RepLKNet 等）都沿用了这一思路——把可融合的多分支设计作为"训练期的可学习结构”。

  2. 简单即高效：在算子库高度优化的今天，“朴素的串联 3×3 卷积"反而是性价比最高的结构，关键在于怎么把它训好。

一句话总结：RepVGG 用"训练三分支、推理一卷积"的重参数化技巧，让老旧的 VGG 架构在精度和速度上都重新具备竞争力。
