SurroundOcc(2023/03)#

SurroundOcc: Multi-Camera 3D Occupancy Prediction for Autonomous Driving

论文链接：​https://arxiv.org/abs/2303.09551

本文提出了一种 SurroundOcc 方法，利用多相机图像预测三维占用状态，以及设计了一种多帧点云构建稠密占用Occ真值的流程。

  1. Pipeline：先为每张图像提取多尺度特征，再采用空间 2D-3D 注意力将其提升到三维体空间，然后应用三维卷积对体素特征进行反卷积多尺度上采样，最后在多个特征层进行占用预测。

  2. 2D-3D Spatial Attention，参考BEVFormer，将BEV query改进为3D volume query，生成Voxel特征而非BEV特征，优化被遮挡或模糊的情况下不同视图的贡献比例。

  3. 生成Occ 数据集：先对动态物体和静态场景的多帧激光雷达点分别进行拼接，再采用泊松重建来填补空洞，最后用最近邻算法对网格进行体素化，以获得稠密占用标签。

RoPETR(2025/04)#

RoPETR: Improving Temporal Camera-Only 3D Detection by Integrating Enhanced Rotary Position Embedding

论文链接：https://arxiv.org/abs/2504.12643

本文提出了定制化的位置编码策略，以增强时序建模能力，在StreamPETR的基础上优化的速度估计（velocity estimation）效果。

  1. 位置编码是为了解决transfomer的置换不变性（顺序和空间位置），以正弦位置编码和可学习位置编码为主。

  2. 3D目标检测中的位置编码：PETR 、3DPPE

  3. 多模态旋转位置编码M-RoPE：将旋转嵌入分解成时间、高度、宽度三分量，实现统一的时空编码。将 BEV 平面表示为 2D 空间域（排除垂直维度即 Z 轴）来简化 3D 嵌入。每个物体的 BEV 中心坐标 (x, y) 被归一化到 [0, 1]² 范围内，并与对数频率向量 ω 相乘，生成旋转角 θx 和 θy。这些角度被应用于自注意力和交叉注意力模块中查询-键（Q/K）运算的通道对旋转，从而显式编码相对 BEV 位置偏移。

  4. 时序：用独立的频率向量 ωt 对归一化的时间标识符（帧 ID）t ∈ [0, 1] 进行编码，导出相应的旋转角 θt。应用这些旋转运算可有效捕获跨帧的时序运动信息。

Sparse4D v2(2023/05)#

论文链接：https://arxiv.org/abs/2305.14018

参考：https://zhuanlan.zhihu.com/p/1944879401704588909

Sparse4Dv2采用Encoder-Decoder架构，Encoder对多视角图像进行编码，提取多视角、多尺度特征图，Decoder由1个单帧层和5个多帧层组成，单帧层包含 3 个子模块：可变形聚合（deformable aggregation）、前馈网络（FFN）以及输出层（特性细化+预测分类和回归结果）。而多帧层除包含上述子模块外，额外引入多头交叉注意力增强时序特征的融合和多头自注意力实现实例之间的特征交互。

  1. 实例时序传递：一个实例由Anchor（结构化信息）、Instance Feature（图像语义信息）以及Anchor Embedding（Anchor向量化）组成，解耦图像特征和先验的几何状态。在递归的时序传递中，当前帧的 Anchor 可以通过前一帧投影得到，投影后的 Anchor 再经过 Anchor Encoder 模块得到 Anchor Embedding，Instance Feature 保持不变。

  2. 高效可变形聚合：整体思路是每个实例 query 都需要从多尺度、多视角的图像特征图上采样信息，然后加权融合。这里的高效是做了算子级别的融合，封装成一个CUDA算子操作，单步输出就能输出 multi-point features，不需要存大量中间变量，显著减少显存访问次数，大幅提升并行度。

  3. 相机参数编码：显式引入相机参数，把从输出空间到图像坐标空间的投影矩阵映射到一个高维特征向量。这个特征向量与实例特征相加，再去计算 Deformable Aggregation 的采样权重。

  4. 稠密深度监督：去掉 v1 里的 depth-reweight 模块，v2在训练阶段额外加了一个 深度监督 分支，用点云提供的真值深度来监督(L1损失)。

StreamPETR(2023/03)#

Exploring Object-Centric Temporal Modeling for Efficient Multi-View 3D Object Detection

论文链接：https://arxiv.org/abs/2303.11926

代码链接：https://github.com/exiawsh/StreamPETR

参考：https://zhuanlan.zhihu.com/p/619293213

本文基于PETR系列的稀疏查询设计，提出了以目标为中心的时序机制，首个性能达到激光感知效果。

整体架构：一个image Encoder提取图像特征、一个内存队列来存储历史的对象查询query，一个propagation transformer模块，这里重点说一下传递注意力模块，每帧对象查询依次和历史查询、图像特征交互，以获得时间和空间信息，输出的查询被进一步用于生成检测结果，并且前K个非背景目标查询被推送到内存队列。通过内存队列的循环更新，从而实现长时间信息被逐帧传播。

  1. 以目标为中心的时序建模：隐式BEV 时序机制，采用当前运动属性（时间、速度、ego姿态）对前一帧query映射到当前时刻，然后再融合到当前帧query。

  2. 运动感知层归一化（MLN）：对运动属性进行编码（姿态、时间戳、速度），并隐式地执行补偿

  3. 混合注意力机制Hybrid Attention layer：不仅仅是self-attention的作用，当前帧query和图像特征交互，还让当前帧query和历史帧query做类似cross attention操作，进行时序的交互。 由于hybrid queries远小于cross attention中 image token的数量，因此所带来的额外计算量可以忽略不计。此外历史object query也会传递到当前帧为当前帧提供更好的初始化（propagate query）。

Sparse4D v1(2022/11)#

Sparse4D: Multi-view 3D Object Detection with Sparse Spatial-Temporal Fusion

论文链接：https://arxiv.org/pdf/2211.10581 代码链接：https://github.com/linxuewu/Sparse4D

参考链接：

  • https://blog.csdn.net/weixin_43163941/article/details/148685632

  • https://baike.baidu.com/item/Sparse4D/63991179

  • https://zhuanlan.zhihu.com/p/1944869098413594105

整个模型架构：多视图先经过Backbone+FPN提取多视角+多尺度+多时序的2D图像特征，再进行6层的Transformer解码Decoder操作提取实例级特征，然后再通过实例级深度重加权模块微调结果，最后接任务检测头。

  1. 这里把Transformer的Cross attention部分换成了Deformable 4D Aggregation算子，从而提取时间和空间的融合特征

  2. 实例级深度重加权模块

Deformable 4D Aggregation 可变形 4D 聚合模块：实例特征质量决定稀疏感知系统表现，该模块以稀疏特征采样与层次化特征融合，来构建空间与时间维度上的高质量实例特征。

  1. 4D关键点生成：见图a部分，

    1. 第一步是对于每个实例候选anchor框，从单一点扩展到多关键点以采样更精细特征.这些关键点分为两部分，（1）一部分是固定关键点 $$k_{F}$$，表征几何先验信息，放置在anchor框的中心和6个面的中心；（2）另一部分是可学习关键点$$k_{L}$$，表征自适应特性，通过网络学习实例的最具表征能力的特征，实现上以实例特征经过子网络预测3D坐标，再计算对应偏移量，用yaw角的旋转矩阵变化，最后以anchor的尺寸和中心位置实现缩放和平移，从而得到可学习关键点的3D坐标。

    1. 第二步是关键点的时序扩展，以提高深度估计精度，实现上采用常速运动模型，按ahncor的速度向量计算当前帧$$t_{0}$$的3D关键点在历史帧$$t$$的位置（这里t0和t应该是时间序列的索引，dt表示时间间隔）。

    1. 再结合自车的运动信息（旋转矩阵和平移矩阵），将这些点统一映射到历史帧坐标系中。

    1. 最终每个 anchor 都能得到一组随时间延展的关键点集合，从而可以通过当前帧提取到不同时序上同一个实例的特征，实现时序上对齐并聚合不同帧的特征。

  2. 特征采样：图b部分，将4D关键点投影到多时间戳/视角/尺度的图像特征图上，并采样相应的特征。例如，我们可能有一个高分辨率的前视图图像特征图和一个低分辨率的后视图图像特征图。我们将关键点投影到这些特征图上，采样得到每个关键点对应的特征向量。这些特征向量可能包含颜色、纹理、形状等信息，用于描述车辆的外观。

  3. 分层特征融合：图c部分，把采样后的特征，按不同 “质量”（比如清晰度、运动显著性 ）或 “尺度”（比如大目标、小目标 ）拆成多组（multi-quality/multi-scale ），用 Group Weights 预测每组特征的 “重要性权重”（比如运动剧烈的帧权重高 ），先对每组用 Linear（线性变换）调整维度，再通过 Aggregate（聚合）逐层融合，最后用 Temporal Fusion（时序融合）+ Linear 输出最终的 实例特征（用于识别、分类等任务 ）

–anchor格式为[x,y,z, l, w, h, sin yaw , cos yaw ,vx, vy], refine offset为A[x,y,z, l, w, h, sin yaw , cos yaw ,vx, vy]

–Anchor总数量为900，其[x,y,z]初始值通过k-means聚类得到，[l,w,h,sin yaw ,cos yaw,vx, vy]初始值为[1,1,1,0,1,0,0];

–利用匈牙利算法进行gt和pred之间one2one的匹配; 与DETR用匈牙利完成检测是端对端检测模型，不需要NMS等后处理检测框

–Loss= ,为L1 loss, 为focal loss, 为cross entropy loss; 框的回归loss，和框的分类loss，以及框的深度loss

–每一层decoder的输出都给予loss进行监督。

BEVPoolv2(2022/11)#

BEVPoolv2: A Cutting-edge Implementation of BEVDet Toward Deployment

论文链接：https://arxiv.org/abs/2211.17111

参考：https://blog.csdn.net/qq_41204464/article/details/136465847

以LSS架构，整个过程分为三个部分：1、生成视锥特征：每个像素有深度信息后，可以结合相机内外参投影到三维空间中；2、预生成三维体素索引：预处理三维体素索引；3.累计求和：将视锥特征按照三维体素索引聚合，然后对同一个方柱区域内，可能存在多个点进行累计求和，压缩形成BEV特征。因此，BEVPool v1版本是利用CUDA对累加操作做了多线程并行加速（BEVFusion？）。BEVPool v2版本是引进视锥体索引进一步优化视锥点云计算，这里是体素索引 + 视锥体索引 实现深度和特征采样，从而避免显式计算、存储和预处理视锥体特征。

1、BevPooling：将所有视锥特征压平到鸟瞰图网格。 问题是彻底丢失高度细节，无法区分立交桥上下或高低物体。

2、VoxelPooling：将 3D 空间划分为固定体素，聚合每个网格内的特征。问题是不同高度特征相互混淆。例如“车身”网格混入“路面”特征。
